# Contributing to Skill Bridge

First off, thank you for considering contributing to Skill Bridge! It's people like you that make Skill Bridge such a great tool for everyone.

## Code of Conduct

Help us keep Skill Bridge open and inclusive. Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md) (coming soon).

## How Can I Contribute?

### Reporting Bugs

- Use the GitHub Issue Tracker.
- Describe the bug and provide steps to reproduce.

### Suggesting Enhancements

- Open a GitHub Issue with the "enhancement" label.
- Explain why this enhancement would be useful.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.
6. Issue that pull request!

## Coding Standards

- **Scripts**: Use Bash/Zsh compatible syntax. Use `jq` for JSON processing.
- **Documentation**: Use consistent Markdown formatting.
- **Skills**: Follow the Skill Bridge skill structure.
