# Skill Bridge Roadmap

This document outlines the planned trajectory for Skill Bridge development.

## Phase 1: Foundation & Documentation (Current)

- [x] Core CLI logic (`sb init`, `sb context`, `sb design`).
- [x] Initial skill indexing via QMD.
- [x] Basic Documentation and Licensing.
- [ ] **Complete Documentation Site**: Deploy the full documentation site with interactive guides.
- [ ] **Markdown Audit**: Ensure all community-contributed skills follow strict formatting rules.

## Phase 2: Knowledge Expansion

- [ ] **Core Skill Library**: Expansion to 50+ high-quality core development skills.
- [ ] **Data Migrations**: Populate `data/migrations/` with standardized JSON maps for common architectural patterns.
- [ ] **Localization**: Support for multi-language context extraction.

## Phase 3: Advanced Tooling

- [ ] **`sb upgrade`**: Seamless CLI versioning and skill library updates.
- [ ] **`sb debug`**: Advanced diagnostic mode for context retrieval issues.
- [ ] **Custom Plugin Support**: Allow users to extend the `sb` pipeline with custom logic.

## Phase 4: IDE Native Integrations

- [ ] Dedicated VS Code Extension.
- [ ] First-class support for JetBrains IDEs.
- [ ] Seamless integration with more AI agents (e.g., Aider, Claude Code).
